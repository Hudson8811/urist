# АРСЕНАЛ — адаптивная HTML-вёрстка

Статический макет по предоставленному изображению: HTML5, CSS3 и обычный JavaScript. Без фреймворков, сборщика, внешних шрифтов и зависимостей сайта. Разметку можно перенести в шаблоны WordPress.

## Открыть

Откройте `index.html` в браузере. Интернет для самой страницы не нужен: изображения и иконки локальные, SVG-спрайт встроен в HTML.

Для просмотра по локальному адресу при установленном Node.js: `node preview/server.cjs`. Адрес: `http://127.0.0.1:4173`.

## Файлы

- `index.html` — семантическая разметка всех секций и двух диалоговых окон.
- `assets/css/style.css` — общие переменные, БЭМ-блоки, адаптив и состояния.
- `assets/js/main.js` — меню, диалоги, карусели, FAQ и формы.
- `assets/images/` — четыре WebP-изображения, SVG-логотип, иконки и схема расположения офиса.
- `preview/` — скриншоты, локальный сервер и результаты проверки. Для размещения сайта эта папка не нужна.
- `ASSETS.md` — происхождение и описание иллюстраций.

## Макет и адаптив

Основной десктоп: 1440 px, максимальная ширина контента 1320 px. Фон секций занимает всю ширину экрана. Адаптив проверен на 320, 375, 390, 600, 768, 1024, 1280, 1440 и 1920 px.

Основные границы адаптива: 1199, 991, 767 и 479 px. На телефоне меню раскрывается, услуги и отзывы перелистываются кнопками, точками и свайпом, преимущества прокручиваются горизонтально, этапы работы идут вертикально. Нижняя форма заменяется кнопкой открытия диалога. Контактные данные и подвал доступны и на телефоне.

БЭМ: `block`, `block__element`, `block--modifier`, `block__element--modifier`. Поведение подключается через `data-*`, классы отвечают за оформление.

## Формы

Кнопки консультации, услуг и форматов обращения открывают общее модальное окно. Тема обращения попадает в скрытое поле `subject`. Есть проверка телефона, обязательное незаполненное заранее согласие, закрытие по Escape, клику на подложку и кнопке закрытия. Нативный `dialog` удерживает фокус, а после закрытия возвращает его на вызвавшую кнопку.

Сейчас `data-endpoint` пустой. Форма проверяет поля и честно показывает: «Это демонстрация: заявка не отправлена». Данные не сохраняются и никуда не передаются.

Подготовлен интерфейс дальнейшей отправки: если заполнить `data-endpoint`, JavaScript передаст `FormData` POST-запросом. Поля: `subject`, `phone` (в формате `+7XXXXXXXXXX`), `consent`, в диалоге также `name`, `message`. Дополнительные скрытые поля, например `action` и nonce, также попадут в запрос. Ожидается JSON-ответ `{ "success": true }`; сообщения об ошибке, повторная отправка и тайм-аут предусмотрены.

## Перенос на WordPress

1. Разнести шапку и подвал по `header.php` / `footer.php`, содержимое — в `front-page.php` или отдельные части шаблона.
2. Подключить CSS и JS через `wp_enqueue_style` / `wp_enqueue_script`, обновить пути к локальным изображениям.
3. Вынести услуги, отзывы, FAQ, контакты и тексты в поля сайта. Сохранить существующие БЭМ-классы и `data-*`.
4. Реализовать серверный обработчик, валидацию, проверку nonce и защиту от спама; указать его адрес в `data-endpoint`.
5. Подключить реальную отправку и заменить демонстрационное уведомление и текст обработки данных утверждёнными текстами проекта.

В этой поставке нет PHP-обработчика и настройки почты.

## Материалы макета

Изображения созданы ImageGen по мотивам референса. Фото офиса — иллюстрация, портреты вымышленные. Отзывы, цифры, адрес и телефон перенесены из макета и не являются результатом проверки деятельности компании. Логотип перерисован в SVG и приблизительно повторяет референс; его можно заменить оригинальным файлом. Карта — локальная схема со ссылкой на поиск адреса в Яндекс Картах.

## Проверка

Проверены отсутствие горизонтального переполнения на девяти ширинах, загрузка изображений, мобильное меню, смена карточек, FAQ, контекст заявки, валидация телефона, вложенное информационное окно, возврат фокуса, закрытие по Escape и подложке. Подготовленный интерфейс отправки проверен перехватом запроса в браузере, без реальной передачи данных.

Актуальные скриншоты: `preview/desktop-1440.png`, `preview/desktop-768.png`, `preview/desktop-390.png`, `preview/modal-desktop.png`, `preview/modal-mobile.png`. Отчёт: `preview/checks.json`.
